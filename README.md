# Program Explanation
This program is intended to be an inventory, or digital storage, system. You should be able to sort by multiple factors. These optional filters should also be reversible.

# Installation
1. You will need to clone this repository.
```git clone```

2. Enter the directory where you put this project.

3. Compile the main.c file and name the output file. 
```gcc ./main.c -o execute```
4. Run the program by using the named output. For example:
```./execute```
5. The contents of the inventory will be saved to, and loaded from, "inventory.dat" in the program folder.
